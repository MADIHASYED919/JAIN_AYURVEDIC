# Setup Guide

## Clone Repository

```bash
git clone your_repository_link
```

---

# Install Frontend

```bash
cd client
npm install
npm run dev
```

---

# Install Backend

```bash
cd server
npm install
npm start
```

---

# Environment Variables

Create `.env` file inside server folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_url
SESSION_SECRET=your_secret
EMAIL_USER=your_email
EMAIL_PASS=your_password
```
